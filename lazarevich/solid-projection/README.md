# Тело, ограниченное поверхностями, и проекция на xOy

## Поверхности

1. \(x^2 + y^2 - 2y = 0\) ⟹ \(x^2 + (y-1)^2 = 1\) — круговой цилиндр (ось ∥ Oz, центр \((0,1)\), радиус \(1\)).
2. \(3y^2 + z - 3 = 0\) ⟹ \(z = 3(1 - y^2)\) — параболический цилиндр (образующие ∥ Ox).
3. \(z = 0\) — плоскость xOy (основание).

## Тело

Тело — множество точек внутри цилиндра между основанием \(z = 0\) и верхней поверхностью \(z = 3(1-y^2)\):

\[
\Omega = \bigl\{ (x,y,z) : x^2+(y-1)^2 \le 1,\ 0 \le z \le 3(1-y^2) \bigr\}.
\]

Условие \(z_\text{верх} \ge 0\) даёт \(|y| \le 1\). У цилиндра \(y \in [0,2]\), поэтому реально \(y \in [0,1]\).

## Проекция на xOy

\[
D = \bigl\{ (x,y) : x^2 + (y-1)^2 \le 1,\ 0 \le y \le 1 \bigr\}
\]

— полудиск круга с центром \((0,1)\) и радиусом \(1\), лежащий не выше диаметра \(y = 1\).
