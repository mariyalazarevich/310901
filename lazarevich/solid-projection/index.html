Тело, ограниченное поверхностями

Уравнения

x² + y² − 2y = 0
3y² + z − 3 = 0
z = 0

Поверхности

  • Цилиндр: x² + (y−1)² = 1 (ось ∥ Oz, центр (0,1), R=1)
  • Параболический цилиндр: z = 3(1 − y²) (образующие ∥ Ox)
  • Плоскость z = 0 (основание)

Проекция D на xOy

Тело лежит между z = 0 и z = 3(1−y²) внутри цилиндра. Высота ≥ 0 при |y| ≤ 1; цилиндр даёт y ∈ [0, 2], поэтому

D = { (x,y) : x² + (y−1)² ≤ 1,   0 ≤ y ≤ 1 }

Полудиск круга с центром (0,1) и радиусом 1, лежащий ниже диаметра y = 1 (включая границу).
